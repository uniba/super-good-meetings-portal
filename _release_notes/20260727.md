## 機能改修

* ミーティングの一括作成機能を正式リリースしました
* ミーティングサイクルの UI を調整しました
* 祝日・土曜・日曜が日付の色で視認できるようになりました。マウスオーバーすると何の日か知ることもできます
* タイマー・時刻・残り時間・日付などの数字を、桁ごとに幅が揃った表示にしました
* アジェンダタイムラインの「タイマー」「通知音」ボタンの表示を整理し、ラベルを簡潔にしました
* ネクストアクションの完了・未完了を切り替えたとき、その項目がその場に残るようになりました
* 設定画面の UI 要素の角丸を調整しました

## 不具合修正

* 単体ミーティングで、残っているネクストアクションが表示されない問題を修正しました
* アクセス権のないページを開いたあと、ブラウザの戻るで閲覧できるページに戻っても画面が切り替わらない問題を修正しました
* ミーティング詳細のヘッダーからミーティングを追加したとき、ほかの人の画面に反映されない問題を修正しました
* 隔週などの間隔のある会議サイクルで「ミーティングを追加」したときに、日付が意図した週からずれることがある問題を修正しました
* アジェンダのドラッグ＆ドロップ時に発生する問題を修正しました
* 会議が予定より早く進んだとき、アジェンダの経過時間が 0 分のまま止まってしまう問題を修正しました
* タイマー表示で、スキップしたアジェンダ分の番号が飛んでしまう問題を修正しました
* 編集中に通信が切れて再接続したとき、入力中の内容が古い状態に巻き戻ることがある問題を修正しました
* 完了したネクストアクションのチェックを外しても、ページを行き来するとチェックが復活してしまう問題を修正しました
* 複数の担当者を割り当てたネクストアクションで、アイコンが縦に積まれて表示が崩れる問題を修正しました
* アジェンダの更新履歴で、ゲストの更新者のアイコンが表示されない問題を修正しました
* ごみ箱で、アジェンダを完全に削除できない問題を修正しました
* 議論内容などのエディタで、字下げした箇条書きの行頭で delete を押すとリストの構造が壊れる問題を修正しました
* とても大きな画像をアップロードするとエラーになる問題を修正しました。サイズの上限を超える画像は、アップロード時にメッセージでお知らせします
* ダッシュボードのミーティング画面で、スクロールバーが二重に表示される問題を修正しました
* 会議体の議事録一覧画面で、スクロールバーが領域の端に表示されない問題を修正しました
* プロジェクトのタイムラインで、「今日に移動」ボタンが横スクロール中に明滅する問題を修正しました
* プロジェクト設定のオーナー表示の文字がずれる問題を修正しました（Windows 環境）
* フォントの変更にともなう各画面の表示崩れを修正しました

## プロダクトオーナー定金からひとこと

* 定期的な曜日・時間を指定してミーティングを作成することができるようになりました。会議を連続的なものとして捉えることで、目標が達成しやすくなります。迷ったらとりあえず 3 ヶ月ぐらい先まで会議を入れておくことをおすすめします。
* 日程の表記で、土・日・祝日がわかりやすくなりました。定例会議で物事を進める皆さんにとっては、祝日で会議のリズムが崩されるのは大きな悩みですよね？事前に祝日がわかりやすくなりましたので、日程調整がはかどります。
